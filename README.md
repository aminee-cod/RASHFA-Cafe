# ☕ RASHFA Cafe - Online Ordering Platform

A fully responsive web application for RASHFA Cafe, designed to provide a seamless online ordering experience. Customers can browse the menu, customize their orders, manage their cart, book tables, and leave reviews - all with a beautiful, warm interface that reflects the cafe's cozy atmosphere.
