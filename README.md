# ☕ RASHFA Cafe - Online Ordering Platform

A fully responsive web application for RASHFA Cafe, designed to provide a seamless online ordering experience. Customers can browse the menu, customize their orders, manage their cart, book tables, and leave reviews - all with a beautiful, warm interface that reflects the cafe's cozy atmosphere.

**[Try the website now](https://rashfa.netlify.app/)**

##  Pages

| Page | Description |
|------|-------------|
|  **Home** | Hero section with stats, featured items, and cafe atmosphere |
|  **Menu** | Filterable product categories with search and customization |
|  **Cart** | Order summary, delivery options, promo codes, and checkout |
|  **Reservations** | Table booking form with booking history management |
|  **Reviews** | Customer feedback with rating breakdown and submission |
